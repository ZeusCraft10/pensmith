# Pensmith — Developer Notes

## Layout

- `bin/` — the CLI (TypeScript): `bin/pensmith.ts` dispatches the verbs in
  `bin/cli/`, which call the workflow code in `bin/lib/`.
- `hooks/` — the source of the plugin's one hook (SessionStart).
- `plugin/` — the installed payload. `plugin/dist/` and the copied assets are
  generated by `npm run bundle` and gitignored; the manifest, skill,
  `hooks/hooks.json` and `bin/` shims are hand-written. A release publishes
  the built `plugin/` on the `release` branch. See CONTRIBUTING.md.
- `templates/`, `references/` — prompt templates, CSL styles, presets and
  locked user-facing copy, read at run time (and copied into `plugin/`).
- `workflows/` — the older per-verb workflow notes; nothing at run time reads
  them.

## Building

The plugin bundle is not committed, so a fresh clone needs a build before
`claude --plugin-dir plugin`, `npm link` or the tests:

```bash
npm ci
npm run build    # tsc -> dist/ (used by the CLI contract tests)
npm run bundle   # esbuild -> plugin/dist/ (gitignored; the tests and the plugin use it)
```

`npm run build` runs `scripts/prebuild.mjs` first, which writes the
gitignored `bin/lib/version.generated.ts` from package.json.

## Test runner

`npm test` runs `node scripts/run-tests.mjs`, which programmatically discovers `tests/**/*.test.ts` (no shell glob — works identically on linux, macos, and windows) and executes them via `node --import tsx --test`. The runner exits 1 if zero test files are found (avoids vacuous CI pass on Windows).

Run the suite with isolated global state, so it never reads your real
`~/.claude` or pensmith data folders:

```bash
export HOME=$(mktemp -d) XDG_DATA_HOME=$(mktemp -d) XDG_CONFIG_HOME=$(mktemp -d) XDG_CACHE_HOME=$(mktemp -d) LOCALAPPDATA=$(mktemp -d)
npm test
```

## OneDrive / iCloud / Dropbox / Google Drive

If your repo lives inside a sync folder (the upstream dev folder is `Documents/Github/pensmith` inside OneDrive), exclude `dist/` and `node_modules/` from sync to avoid build-time races. `pensmith doctor` surfaces this warning for `.paper/` workspaces; the same advice applies to the dev tree.

## Quick check

`npm run check` runs prebuild, lint, typecheck, build, the bundle and the tests in one shot.
