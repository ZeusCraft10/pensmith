## Method

### Environment

- Every CLI run used the built snapshot, `node /home/user/pensmith-sweep/dist/bin/pensmith.js …`, from temp dirs under the session scratchpad (`scratchpad/sweep/<batch>/`), with `XDG_DATA_HOME` (and usually `HOME`) set inside them and never with the cwd inside a repo checkout. The scratch dirs are session-local and not committed; the `$S`, `$B` and `$SW` paths in the Command column refer to them.
- No API keys exist in this environment. The code has no LLM base-URL override (`bin/lib/anthropic.ts:150` hard-codes `https://api.anthropic.com/v1/messages` and `:177` `https://api.openai.com/v1/chat/completions`; `runtime.json` has no endpoint field, and a `baseUrl` there is silently dropped). Where an LLM was needed, each batch ran a small local mock server on 127.0.0.1 answering in the Anthropic Messages shape with prompt-format-correct output, reached by preloading a hook (`node --import <hook.mjs>`) that installs an undici global dispatcher routing `api.anthropic.com` (and, where needed, `api.openai.com`, `api.unpaywall.org`, `api.gptzero.me`) to the mock; `http.ts` uses undici `request`, which honours the global dispatcher. A dummy `ANTHROPIC_API_KEY` passes the fail-loud key probe. SWEEP-01's text names "the RUN-21 mock"; RUN-21 has not landed yet, so these per-batch mocks stood in for it. Request bodies were captured for prompt inspection.
- Network: this snapshot replays offline cassettes by default (`PENSMITH_NETWORK_TESTS` unset); runs marked live used `PENSMITH_NETWORK_TESTS=1` against the real services. Both modes were exercised wherever the default mode changes the outcome.
- Tools: pandoc and PyMuPDF are not installed system-wide. B3 used pandoc 3.9 from its scratch dir and installed pdflatex (texlive) to test the PDF path; B4 installed PyMuPDF 1.28.2 into scratch to generate PDFs and exercise the fallback. Humanizer checks used a fake `HOME` containing `~/.claude/skills/humanizer/SKILL.md`. Tier-1 checks used Claude Code 2.1.283 at `/opt/node22/bin/claude` with an isolated `CLAUDE_CONFIG_DIR`, plus a stdio MCP client against `dist/mcp/server.js`. Node is v22.22.2. CI evidence comes from GitHub Actions run 36335325302 at `8dc75b4`.
- No source file was modified. Probe files for the lint checks (REPO-05, ARCH-08) were placed only in a scratch clone and deleted.

### Verdicts

- **done**: works as the requirement states on the real user path, shown by a command and its observed output. A unit test with pre-seeded state is not enough.
- **partial**: works in part; the evidence names the missing part.
- **broken**: fails when exercised, or is not implemented at all.
- **no-op**: runs and reports success but changes nothing observable.
- **stub**: present only as a test seam or placeholder on the user path.
- **placeholder-fed**: the step runs but receives fixed, empty or wrong inputs, so its output cannot be right.
