## Deviations (with D-ids)

- **D-19-21 "one lookup request per PDF".** A PDF identified by an identifier or a Crossref title hit sends exactly one request (asserted). A PDF whose title Crossref does not match confidently also goes to OpenAlex (D-19-20 names both), so a no-match PDF sends two requests, each carrying only the title (asserted). PRIVACY.md and `workflows/new.md` say "one lookup per registrar consulted".
- **D-19-20 identifier hits.** A DOI or arXiv id found in a PDF's text is accepted only when the returned record's title appears on the PDF's first pages (a reference-list DOI must never name the paper); otherwise identification falls through to the title search. Metadata identifiers are trusted as-is.
- **D-19-21 offline.** With sources offline and no recorded answer, a BYO PDF is skipped with `identifying it needs the network (offline) — re-run online to add it` rather than kept unhydrated: "no confident match" is a registrar answer, "offline" is not.
- **D-19-27 wording.** The Phase 17 lines are kept where tests and REQUIREMENTS pin them: `<DOI|arXiv|PMID|ISBN> verification unavailable (<mode>) — <id> NOT added; re-run online to verify and add it`, `… is a reserved dry-run identifier (…). Source NOT added.`, `added <key>.` (the title follows on its own line) and the RUN-28 line `remap skipped (non-interactive); run pensmith add --remap <key> --section N`. New failure lines end `— nothing added`.
- **D-19-21 GROBID** and research's ingest of new files in `byo_pdf_dir` are not in this stream (net and research own them; integration wires them). PRD §7.15 / §9 do not claim them.
- **D-19-20 `add <dir>`** does not remap; it prints `pensmith add --remap <citekey> [--section N]`.

## Hand-offs to the integration pass

- **library ← adapters.** `source-input.ts` `lookupIdentifier` picks each adapter from the one registry by name (`crossref`, `arxiv`, `pubmed`, `books`) and uses `lookupById` when the adapter has it, else `fetchById`. Until `books` exists, `add isbn:<ISBN>` reports `lookup failed (no book (ISBN) lookup is available in this build)`, exit 1. The books adapter is called with `isbn:<ISBN13>`; adjust `adapterId` if its `lookupById` takes the bare ISBN. The arXiv adapter in this base returns no abstract, so arXiv entries have no `abstract` field until the adapters stream maps `summary`.
- **library ← net.** `pdf-identify.ts` `identifyPdf` is the place for `grobidHeader` (first, when `PENSMITH_GROBID_URL` is set); `IdentifyDeps` already abstracts the lookups.
- **research ← library.** Research ingests new PDFs in `[sources] byo_pdf_dir` first with `ingestByoPdfs(root, files, { provenance: 'byo' })` (`listPdfsInDir` for the file list; re-ingest is a no-op by sha256). The `research-prune` gate's "add a source" input can go through `classifySourceInput` + `lookupIdentifier` + `upsertSources`.
- **Recordings.** The identification lookups of every `tests/fixtures/byo/` PDF (the arXiv id and the nphys1170 DOI are already recorded; the title searches of `attention-title-only.pdf` and `no-match.pdf` and the `nature14539` DOI of `metadata-doi.pdf` are not) and the `add` identifier forms (PMID, ISBN) for the fixture lane.
- **GRND-14 acceptance** is merge-time (below).
