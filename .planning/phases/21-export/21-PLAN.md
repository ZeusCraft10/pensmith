**Base:** `57f132c` (`akhil/pensive-faraday-qx3o58`, Phases 17–20 and 23a merged) · **Decisions:** [21-CONTEXT.md](21-CONTEXT.md) (D-21-01 … D-21-29) · **Streams:** `export`, `pipeline` (parallel worktrees), then one integration pass.

## 1. Goal

Compile produces a smoothed, checked, correctly cited paper with a title and section headings; done humanizes for real through the configured model, scores honestly with explicit and persisted detector consent, runs a real plagiarism check, and exports every requested format — with or without pandoc — in the paper's citation style with zero trace; outline-only mode ends in a re-verified, zero-trace sourced outline and annotated bibliography. Every requirement holds on the real user path (the built CLI in a temp dir, a real exported file) and is covered by tests. The roadmap's eight success criteria (ROADMAP.md, Phase 21) are the definition of done.

## 3. Design

### 3.1 The load-bearing decisions

All decisions are in 21-CONTEXT.md. The ones every stream must hold in mind:
- The gate core (`verify/gate.ts` `recomputeGate`) is never bypassed: done gates DRAFT.md before any paid or third-party step and gates the humanized text before it becomes FINAL.md; outline mode gates its listed sources; the exporter renders only what the gate read (D-21-12).
- Zero trace is checked, not assumed: the scanner runs on every written file and deletes on a hit (D-21-08).
- A requested format is never silently replaced (D-21-02). md never uses pandoc.
- One rewrite guard for every model rewrite of verified prose (D-21-14); one acceptance function for the humanized text in both tiers (D-21-18).
- Nothing new is a 17th verb; no new prompt slug except `claim-consistency` (D-21-15); the humanizer is a model slug with no template (D-21-18).
- Every new persisted field ships its migration: config v4, COMPILE-INPUTS v3, DONE-RECORD v2 (S-20).

### 3.2 What compile and done do after Phase 21

**compile** (unchanged steps marked =): (=) lock, outline + registry checks, per-section records, staleness re-verify, gate core per section → refuse; (new) the title/headings check (D-21-13); (=) concatenate, now with `# title` and `## section` headings; (new) per-boundary smoothing through the rewrite guard, or a recorded skip; (=) surface consistency scan; (new) contradiction candidates → heuristic → one capped `claim-consistency` call or a recorded skip; (changed) density with its sources; (changed) COMPILE-REPORT with transitions text, advisory findings, contradictions, skip reasons; (changed) COMPILE-INPUTS v3.

**done** (draft mode): parse and validate flags (`--format`, `--style` → `resolveExportStyle`, `--only`, the `--no-verify --raw` rule) → (outline mode → `runOutlineDone`, §3.3) → the blocking gate over DRAFT.md (=, VRFY-26/27) → the non-TTY confirmation pre-check (=) → plagiarism (unless skipped) → honesty before (unless skipped) → humanizer → `acceptHumanized` (reject → EXIT_BLOCKED) → honesty after → whole-paper Pass 4 (unless `--no-verify`) → the confirmation gate (lists UNSUPPORTED claims, orphans, plagiarism hits, contradictions from COMPILE-REPORT, accepted quotes) → `exportDraft` (scan inside; ZeroTraceError → EXIT_ERROR) → `last_verified` and retraction statuses (=) → `.paper/VERIFICATION.md` → FINAL.md + DONE-RECORD. Each `--only` mode runs the subset D-21-23 names.

### 3.4 File formats

- **DRAFT.md (compiled):** `# <title>\n\n## <§1 title>\n\n<§1 draft>\n\n## <§2 title>\n\n…`, outline order, LF.
- **COMPILE-INPUTS.json v3:** v2 plus `headings_sha256` (sha256 of the title and the section titles, one per line, in order). `migrations/compile-inputs/v2_to_v3.ts` leaves it absent; an absent value is stale (D-21-13).
- **COMPILE-REPORT.md:** frontmatter as now (`title` filled); body sections in order: Transitions Changed (each `boundary 1→2: smoothed | rejected (<reason>) | skipped (<reason>)` with `before:` / `after:` text) · Cross-Section Consistency Flags · Citation Density (discipline and source, band and source, per section, out-of-band paragraphs) · Compile-Staleness Resolved · Advisory Findings (per section: Pass-2 non-SUPPORTED rows and Pass-4 orphans, or "not run on the current draft") · Accepted Quotes · Quotes Verified Against Your Files · **Contradictions** (`Contradictions flagged: N (target 0)`, pairs with both sections and sentences and their source — model or heuristic, the cleared pairs, the skip reason).
- **.paper/VERIFICATION.md (done):** as now, with the honesty section as `before: <n>% AI-generated (<backend>, <ISO>)` / `after: …` or the exact skip reason (D-21-20), the plagiarism section with per-phrase location and real URLs or its skip line, and `## Whole-paper Pass 4` or `skipped (--no-verify)`.
- **config.toml v4:** D-21-26.
- **DONE-RECORD.json v2:** v1 plus optional `mode: 'draft' | 'outline'` (absent = draft), and for outline mode `outline_sha256`, `bib_sha256`, `annotated_sha256`; `migrations/done-record/v1_to_v2.ts`; read through the versioned loader (a newer record is refused, never overwritten).
- **.paper/ANNOTATED-BIBLIOGRAPHY.md:** `# <title> — Annotated Bibliography`, then per source (outline-assignment order, deduplicated): the reference in the resolved style; `Type:` tier; `Summary (abstract excerpt):` ≤ 60 words or `no abstract available`; `Why it is relevant:`; `Supports:` `§1 <title>; §3 <title>`.
- **export/:** `DRAFT.<ext>` (draft mode) or `OUTLINE.<ext>` and `ANNOTATED-BIBLIOGRAPHY.<ext>` (outline mode), `CITATIONS.bib`, `CITATIONS.ris` (same key set); `.dry-run` naming under `--dry-run` (as now).

## 4. Parallel execution protocol

1. Each stream works in its own worktree on its own branch (`v1/p21-export`, `v1/p21-pipeline`) cut from the plan commit, and edits only its owned paths (§5) plus the localized hunks §6 assigns to it. Needing anything else is a stop-and-report, not an edit.
2. Commit small and often (`feat(21-export): …`, `feat(21-pipeline): …`, `wip(21-…)` allowed), with the two trailer lines. Never push.
3. Keep every interface in §3.3 backward compatible; code against the base signatures; leave the cross-stream wiring to §7.
4. New terminal output goes through `out()` (PLUG-13); stderr writes stay `process.stderr.write`.
5. Tests: every requirement's behaviour is tested through the real path the stream owns; a CLI-level check that needs the other stream's half is listed for the integration pass instead of being faked. No `test.skip`/`todo`, no loosened assertion. Pre-existing RED-by-skip guards in a file a stream rewrites (`honesty.test.ts`, `humanizer-task.test.ts`, `humanizer-wrap.test.ts`) become unconditional tests.
6. Before handing over: `npm run prebuild && npm run lint && npm run typecheck && npm run build && npm run validate:manifests`, the stream's own tests, then the full `LANG=C.UTF-8 CI=true npm test` with pandoc 3.9 on PATH (only the root-only atomic-write case may fail), `npm run test:tier-contract`, then `npm run bundle` and commit `plugin/dist/` and the re-stamped `plugin/.claude-plugin/plugin.json` (the integration pass regenerates them again after the merge; never hand-merge them).
7. Each stream writes `21-<stream>-SUMMARY.md`: what it built, decisions it made inside its scope, tests updated (with reasons), user-path evidence, and **every changed or added exported signature** (for the "Merge notes for Phase 23b").
8. Privacy: fixtures and cassettes contain no personal data; the polite-pool email is `pensmith-dev@example.org`; cassettes are ≤ 51200 bytes and hold no auth headers.

## 10. Risks

- **citeproc-js vs pandoc's citeproc.** The engines differ on some CSL rules (sentence case, link wrapping, `Published online`). D-21-05 allows named bibliography-text exceptions only; in-text forms must match. If an in-text difference appears it is fixed in the renderer, not excepted.
- **Built-in PDF layout.** Line breaking, footnotes at the foot of the page and font subsetting are the largest new code; keep the layout model simple (one column, fixed margins, no hyphenation) and prove it with text extraction and page-count checks.
- **Markdown subset drift.** The built-in writers must read the gated text as pandoc does; the AST differential (task 5.1.9) is the guard; anything outside the subset is written literally, never dropped.
- **Licences.** The font (OFL) and the word-frequency list must permit redistribution in an AGPL-3.0 package; record both licences in the repo and README credits. Pick a list whose licence is unambiguous.
- **Cost (S-22).** The smoother, the contradiction call and the humanizer add spend; D-21-27 re-checks the default paper under the $5 cap.
- **Detector APIs.** No keys: request shapes come from vendor documentation and are tested against mocks; keyed live runs are maintainer items. Sapling's key placement must stay out of logs and the `--show-prompts` mirror.
- **DuckDuckGo blocking.** The live plagiarism lane may be throttled or blocked; report what happened, never a fabricated result.
- **Phase 23b merge.** 23b shims the smoother, the humanizer and done's decisions; every signature change is listed (§7.7), moved `done.ts` exports stay re-exported, and no file under `mcp/` or `plugin/skills/` changes here.
- **Two streams on done.** The done.ts hook and `done.md` subsections are the only overlap; §7.2 resolves them.
