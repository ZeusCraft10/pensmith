## 5. Caveats and follow-ups (not Phase 18 gaps)

1. **VRFY-13 (Phase 20), with Phase 19 adapter normalisation.** Pass-1 author matching reports MIS-CITED for real sources with PubMed "Family Initials" names (`Aziz FI`, `Talaat FM`) and compound surnames stored inverted (`Victor Vieira de Paiva, Pedro`), because authorJW falls below 0.85 while titleJW is 1.00. It fails closed, as the gate should, but it means an unattended live `--yolo` run of the §15 assignment stops at attention until `plan N --revise` removes the flagged citations (U1). 18-CONTEXT "Deferred" records a live-lane check that the §15 assignment reaches done unaided, which that phase should run.
2. **REV-03 (Phase 22).** `plan N --revise` removes one flagged citation per invocation, so U1 needed three runs for three rows.
3. **EXP-04 (Phase 21).** Without pandoc, the md export of a note style (Chicago notes-bibliography, U5) renders the full note inline and leaves a doubled period after the DOI.
4. **Intake (minor).** `disciplineMentionFrom` does not read a bare course-code line (`Biology 210: …`). It does read "for my Biology class", `Course: Biology` and similar forms. A real clarifier model suggests the discipline, but the offline stub and mock then default to `other`.
5. **CI-06 (Phase 17), operator step.** Push the branch and record a green `ci.yml` run (Node 22 and 24 × ubuntu, macOS, Windows). That run is also the cross-OS evidence for this phase's new parsers (CRLF paths are unit-tested), workspace copies, archive moves and the fake-TTY preload.
6. **PLUG-01 / CI-05 (Phase 23).** `claude plugin validate .` fails on the `plugin.json` `skills` shape (§1).
